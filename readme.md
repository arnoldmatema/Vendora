# Vendora

Vendora is a Customer-to-Customer (C2C) e-commerce marketplace developed using PHP, MySQL, HTML, CSS, and JavaScript. The platform allows users to create accounts, list products for sale, browse available products, and manage their profiles. It also includes an administrator dashboard for managing users and product listings.

## Features

### User Features
- User registration and login
- Browse product listings
- Create and manage product listings
- Upload product images
- View user profile
- Secure session management

### Admin Features
- View all users
- View all product listings
- Delete product listings
- Manage user roles

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP (Local Development)
